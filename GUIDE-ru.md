## О проекте

NiceTab — бесплатное открытое расширение для управления вкладками браузера. Это функциональная замена OneTab, Toby, SessionBuddy и похожих инструментов: много возможностей и удобный интерфейс.

Обзор проекта — в <a href="./README-ru.md">README</a>.

## Установка

**Способ 1. Из магазина расширений**
- Google Chrome: [Chrome Web Store](https://chromewebstore.google.com/detail/fonflmjnjbkigocpoommgmhljdpljain)
- Microsoft Edge: [Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/ompjiaelpibiggcnanhbdblkhfdmkgnl) (из-за более долгой модерации релизы могут отставать от Chrome)
- Firefox: [Firefox Browser Addons](https://addons.mozilla.org/firefox/addon/nice-tab-manager)

**Способ 2. Ручная установка из ZIP**
- Скачайте `nice-tab-<version>-chrome.zip` (для Chrome/Edge) или `nice-tab-<version>-firefox.zip` со страницы [Releases](https://github.com/web-dahuyou/NiceTab/releases).
- Чтобы загрузить распакованное расширение, см. документацию Chrome/Edge для разработчиков или найдите инструкцию «как установить распакованное расширение Chrome».

После установки **закрепите значок расширения**, чтобы быстрее открывать функции.

При первом запуске список пуст — вкладки ещё не отправлялись. Щёлкните правой кнопкой по значку и выберите **Отправить все вкладки**.

NiceTab поддерживает сочетания клавиш. Их можно посмотреть в контекстном меню или настроить на странице сочетаний браузера (см. [Привязка сочетаний клавиш](#привязка-сочетаний-клавиш)).

## Обзор возможностей

Главное в NiceTab — отправить вкладки в структурированный список одним щелчком и управлять ими по схеме `Категория > Группа вкладок > Вкладка`.

Три основных интерфейса:
- [Контекстное меню расширения](#контекстное-меню-расширения)
- [Popup-панель значка](#popup-панель-значка-расширения)
- [Панель управления](#панель-управления); отображается как `панель NiceTab`.

Попробуйте щелкнуть по значку левой и правой кнопкой.

### Контекстное меню расширения

После установки список пуст. Щёлкните правой кнопкой по значку NiceTab и отправьте открытые вкладки на страницу управления.

Пункты меню:
- **Открыть панель NiceTab**: открывает страницу управления.
- **Глобальный поиск**: поиск вкладок, отправленных в NiceTab. См. [Глобальный поиск](#глобальный-поиск).
- **Отправить все вкладки**: все открытые вкладки текущего окна.
- **Отправить вкладки всех окон**: все открытые вкладки во всех окнах.
- **Отправить текущую группу**: группу с активной или выделенной вкладкой (поддерживается выбор нескольких вкладок и нескольких групп).
- **Отправить текущую вкладку**: активную или выделенную вкладку (вкладки браузера можно выделить несколько).
- **Отправить другие вкладки**: все, кроме текущей выделенной/активной.
- **Отправить вкладки слева**: вкладки слева от текущей.
- **Отправить вкладки справа**: вкладки справа от текущей.
- **Начать синхронизацию**: запуск синхронизации вручную.
- **Усыпить другие вкладки**: усыпить все вкладки, кроме текущей.

**Примечания**:
- v2.8.4: в контекстное меню вкладки Firefox добавлен пункт **Отправить текущую вкладку**.

### Popup-панель значка расширения

Щелчок левой кнопкой открывает `Popup`. Модули: **О расширении**, **Перейти**, **Действия**, **Тема**, **Открытые вкладки**.

**Модули**:
- **О расширении**: сейчас показывается версия (позже может появиться больше сведений).
- **Перейти**: быстрые ссылки
  - Панель NiceTab
  - Привязка сочетаний клавиш
  - Руководство пользователя
- **Действия**: частые операции
  - Отправить вкладки
  - Глобальный поиск
  - Усыпить другие вкладки
  - Начать синхронизацию
- **Тема**: смена цвета темы
- **Открытые вкладки**: открытые вкладки и нативные группы браузера. Можно закрыть, усыпить или переключиться на вкладку.

**Примечания**:
- v2.8.4: кнопка компактного режима.
- По умолчанию левый щелчок открывает `Popup`. В [Панель управления - настройки](#панель-управления---настройки) можно сразу отправлять все вкладки (как в OneTab).
- Гибернация снижает расход памяти, не закрывая вкладки. При переключении усыплённая вкладка снова активируется.

### Панель управления

Панель NiceTab включает страницы **Список**, **Настройки**, **Импорт/экспорт**, **Синхронизация** и **Корзина**.

**Страницы**:
- **Список**: все вкладки в иерархии **Категория > Группа вкладок > Вкладка**. Кроме CRUD есть **сортировка**, **перенос**, **блокировка**, **избранное**, **копирование**, **удаление дубликатов**, **открытие**, **переименование**, **QR-код** и пакетные операции.
- **Настройки**: под разные привычки использования.
- **Импорт/экспорт**: список вкладок и настройки (на диск и обратно в расширение).
- **Синхронизация**: список и настройки в удалённое хранилище (GitHub Gists, Gitee Gists, WebDAV), в том числе автосинхронизация (см. [Панель управления - удалённая синхронизация](#панель-управления---удалённая-синхронизация)).
- **Корзина**: удалённые из списка элементы можно восстановить (корзина очищается каждый день; восстанавливайте в тот же день).

### Подсказки

Одни и те же действия есть в нескольких местах: popup, контекстное меню, панель управления. Так удобнее разным людям:
- Многие закрепляют значок и работают из popup или контекстного меню.
- Кто-то не хочет значок на панели — тогда нужны кнопки на странице управления.
- Частые операции можно повесить на сочетания клавиш.

### Новая вкладка
В версии 3.0.0 можно заменить страницу новой вкладки на `панель NiceTab` или `новую вкладку NiceTab`. Вариант «По умолчанию» вернёт стандартную страницу браузера.

Настройка — на странице `Настройки`.

## Панель управления - операции в навигации

- **Переключение страниц**: **Список**, **Настройки**, **Импорт/экспорт**, **Синхронизация**, **Корзина**.
- **Версия**: обычно текущая версия; при обновлении — доступная версия, щелчок запускает обновление.
- **Цвет темы**: несколько готовых цветов (позже возможны тёмные цвета и расширение палитры).
- **Светлая/тёмная тема**.
- **Язык**: китайский, английский, русский.
- **Прочие действия**: свёрнуты в выпадающий список.

### Создать снимок и восстановить снимок

Оба пункта — в выпадающем меню `«Действия»` навигации. Можно сохранить открытые вкладки как временный снимок и затем восстановить его в браузере.

**Сценарий**: перед ручным закрытием или перезапуском браузера сделайте «Создать снимок», после запуска — «Восстановить снимок».

**Пояснение**:
- Обычно браузер сохраняет вкладки только при своём обновлении или официальном перезапуске. При ручном закрытии снимка нет.
- NiceTab на самом деле пишет снимок в фоне постоянно и восстанавливает его после перезапуска. Отдельный интерфейс управления снимками ещё не готов — возможно, появится позже.

## Панель управления - список

Страница списка устроена как `Категория > Группа вкладок > Вкладка`. Слева **дерево каталогов** (категории и группы), в центре **сохранённый список** (группы выбранной категории и вкладки в них), справа **панель открытых вкладок** (вкладки и группы текущего окна браузера).

### Дерево каталогов

Левое дерево похоже на проводник: категории (первый уровень) и группы вкладок (второй). Есть поиск, сворачивание, перетаскивание, блокировка и перенос между категориями.
- **Буфер**: особая категория, всегда первая, её нельзя удалить. Отправленные вкладки попадают сюда. Группы и вкладки в буфере можно править, переносить и удалять.
- Категории можно сворачивать, удалять и блокировать; **заблокированная категория только для чтения**.
- В категории можно создавать группы и одним щелчком переносить группы в другие категории.
- Категории и группы можно переименовывать, удалять и перетаскивать между категориями.
- Выбор категории или группы показывает в **сохранённом списке** все группы этой категории и вкладки в них.
- Для выбранной категории/группы работают сочетания «вверх/вниз» (только для дерева, пока не настраиваются).
  - Вверх: macOS (⌥ + ⇧ + ↑) Windows (Alt + Shift + ↑)
  - Вниз: macOS (⌥ + ⇧ + ↓) Windows (Alt + Shift + ↓)

### Сохранённый список

**Сохранённый список** показывает все группы выбранной категории и вкладки в них, с виртуальной прокруткой.

Список сгруппирован. Группы можно переименовывать, удалять, открывать в браузере, блокировать, добавлять в избранное, клонировать, копировать ссылки, убирать дубликаты.

**Операции с группой**:
- **Переименовать**: значок правки (есть ограничение длины имени).
- **Удалить**: кнопка «Удалить» у группы.
- **Открыть группу**: открыть все вкладки группы в браузере (можно настроить автоудаление из списка после открытия).
- **Создать группу выше**: новая группа перед этой.
- **Создать группу ниже**: новая группа после этой.
- **Заблокировать**: заблокированную группу нельзя удалить; вкладки внутри нельзя удалять, перетаскивать, переносить и выбирать пакетом.
- **Избранное**: кнопка «Закрепить сверху» закрепляет группу вверху категории, текст меняется на «Открепить».
- **Переместить в**: выбор целевой категории и перенос группы.
- **Копировать ссылки**: имена и URL вкладок группы в буфер обмена по шаблону из настроек (`Настройки > Другие действия > Шаблон копирования ссылок группы вкладок`).
- **Клонировать**: полная независимая копия группы рядом.
- **Убрать дубликаты**: вкладки с одним URL в этой группе.
- **По названию (А→Я)**: сортировка вкладок по имени по возрастанию.
- **По названию (Я→А)**: сортировка вкладок по имени по убыванию.

**Список вкладок**:
- Вкладку можно удалить, изменить, скопировать, показать QR-код.
- Внутри группы — множественный выбор и перетаскивание.
- **Выделение рамкой** для быстрого множественного выбора.
- **Пакетный выбор между двумя вкладками**: Shift + щелчок по одной, затем Shift + щелчок по другой.
- После множественного выбора: пакетное удаление, открытие, перенос, перетаскивание, копирование ссылок, клонирование.
- **Подсказка**: вкладки можно перетащить на группу в дереве слева и быстро перенести в другую категорию.

### Панель открытых вкладок

В v2.9.0 справа появилась «Панель открытых вкладок».

Сворачиваемая панель показывает вкладки и группы текущего окна. Можно быстро выбрать несколько и перетащить в **сохранённый список** или на узлы **дерева**. Можно перетаскивать целые группы.

### Отправка вкладок

Эти пункты сильно влияют на поведение. Настройте их под себя.

| Пункт | Описание | По умолчанию | Важность |

| Показывать окно «Отправить в» при отправке вкладок? | Можно выбрать каталог (Категория > Группа). **Если «Нет», вкладки уходят в группу категории «Буфер»** | Нет | ★★★★★ |
| Отправлять закреплённые вкладки в NiceTab? | Отправлять ли закреплённые вкладки | Нет | ★ |

| Открывать панель NiceTab при отправке вкладок? | После успешной отправки открывать панель, чтобы проверить или продолжить работу | Да | ★★★ |
| Создавать новую группу при отправке одной вкладки? | Если «Нет», вкладка уйдёт в первую незакреплённую и незаблокированную группу в буфере | Да | ★★★ |
| Автоматически закрывать вкладки после отправки? | Закрывать отправленные вкладки в браузере, чтобы экономить память. Чтобы оставить их открытыми, выберите «Нет» | Да | ★★★★ |
| Автоматически закрывать вкладки при выбранных действиях | Действует, если предыдущий пункт «Нет». Закрывать только для части способов отправки | Да | ★★★★ |
| Сохранять дубликаты групп при отправке? | Объединять ли отправляемые группы с одноимёнными в буфере. По умолчанию сохранять | Да | ★★ |
| Сохранять дубликаты вкладок при отправке? | Объединять ли вкладки с одним именем при отправке или слиянии групп. По умолчанию сохранять | Да | ★★ |

### Открытие вкладок

Поведение при открытии вкладок из списка на панели управления.

| Пункт | Описание | По умолчанию | Важность |
| --- | --- | --- | --- |
| Открывать группу вкладок в новом окне? | Открывать группу из NiceTab в новом окне браузера | Нет | ★★ |
| Удалять вкладки из списка NiceTab после открытия? | После открытия вкладок/группы в браузере удалять ли их из списка (если NiceTab как закладки — «Нет»; как временное хранилище — «Да») | Нет | ★★★★★ |
| Автоматически усыплять при открытии нескольких вкладок? | Усыплять вкладки/группу при открытии из списка | Нет | ★★★★ |
| Модификатор для открытия вкладки в фоне | Чтобы открыть вкладку из списка без перехода на неё (остаться на панели), зажмите этот модификатор и щёлкните левой кнопкой. Можно щёлкать несколько вкладок подряд. То же даёт средняя кнопка мыши | Alt(⌥) | ★★★ |
| Модификатор для открытия вкладки на переднем плане | По умолчанию щелчок по вкладке в списке открывает её на переднем плане | Нет | ★★★ |
| Порядок при открытии нескольких вкладок | По умолчанию слева направо. Если браузер открывает вкладки справа от текущей, выберите «Обратный» | По умолчанию | ★★ |
| Восстанавливать безымянную группу как группу вкладок браузера? | Открывать безымянную группу как нативную группу браузера | Да | ★★ |
| Восстанавливать именованную группу как группу вкладок браузера? | Открывать именованную группу как нативную группу браузера | Да | ★★ |

**Примечания**:
- По умолчанию вкладки открываются на переднем плане. Чтобы по умолчанию открывать в фоне, поставьте «Модификатор для открытия в фоне» в `Нет`, а «Модификатор для открытия на переднем плане» — в `Alt(⌥)` или другой (`Alt(⌥)`, `Command(⌘)`, `Shift(⇧)`).
- Если модификаторы фона и переднего плана совпадают, срабатывает открытие на переднем плане.

## Панель управления - импорт и экспорт

Импорт и экспорт списка вкладок и настроек.

### Импорт данных из других расширений

Можно импортировать данные других расширений в NiceTab.

Сейчас поддерживаются:
- NiceTab
- OneTab
- KepTab
- Toby (json)
- Session Buddy

### Режимы импорта

Три режима: добавить, объединить, заменить.

- **Добавить**: новые категории и группы, существующие данные не меняются.
- **Объединить**: импорт сливается с текущими данными; одноимённые категории объединяются.
- **Заменить**: импортированные данные полностью заменяют текущие.

### Источники импорта

Текстовое поле и локальный файл.

В v2.7.7 можно импортировать HTML-файл закладок браузера.

> Примечание: NiceTab не поддерживает бесконечную вложенность каталогов; импорт приводится к структуре **Категория > Группа вкладок > Вкладка**.

### Экспорт

Список вкладок и настройки можно сохранить в локальный файл.

Удалённая синхронизация удобнее экспорта в файл. Потерь на удалённом хранилище пока не было, но периодический локальный бэкап всё равно полезен.

В v2.7.7 данные NiceTab можно сохранить как HTML-файл закладок и импортировать его в браузер.

## Панель управления - удалённая синхронизация

В v2.8.2 можно задать свои удалённые каталоги: разные устройства — разные каталоги в одном аккаунте.

### Текущее состояние

Сейчас это базовая резервная копия, не полноценная синхронизация. Причины:

1. Изначально цель была бэкап и целостность данных: инкрементальное объединение, удаления не синхронизируются.
2. Категории и группы различаются по **именам** (сначала не хранили id). Одинаковые имена допускаются.
3. При слиянии одноимённые категории/группы объединяются. Имя по умолчанию категории — `Unnamed Tag`, группы — `Unnamed Group`. Непереименованные перед слиянием получают случайные имена, иначе все «безымянные» слились бы в одну. В итоге безымянные группы могут продублироваться: расширение не знает, какую локальную `Unnamed Group` сливать с какой удалённой.
4. Из-за этого многие отключали автосинхронизацию. Если категории и группы переименовать, случайных имён и дублей не будет. У многих нет привычки переименовывать (автор переименовывает вручную).
5. Полноценная синхронизация, возможно, появится позже. Если что-то непонятно — лучше обсудить в группе.

### Рекомендуемые сценарии

**Одно устройство**:
- Вручную: периодически «отправить на удалённый сервер — заменить»
- Автоматически: включить автосинхронизацию, тип «Автоотправка (замена)». Удалённая копия будет совпадать с локальными данными.

**Несколько устройств**:
- Вручную
  1. На работе устройство A: сначала «Загрузить удалённые — объединить с локальными» (новые данные = старые A + удалённые). После работы «Отправить локальные — заменить» (удалённые = актуальные A).
  2. Дома устройство B: сначала «Загрузить — объединить» (новые = старые B + удалённые = старые B + актуальные A). Если данные менялись — «Отправить — заменить» (удалённые = актуальные B).
  3. Повторять каждый день.
- Автоматически
  - Способ «Автоотправка (объединение)». При каждом запуске удалённые данные сливаются с локальными и отправляются обратно (удаления не синхронизируются, данные только накапливаются).
  - Если это неудобно, лучше синхронизировать вручную (автор предпочитает ручной режим).

### Удалённая резервная копия

В версии 2.9.2 при отправке на удалённый сервер сначала сохраняется копия удалённых данных (каталог и имя файла можно задать), затем отправляются локальные.

> Копия на одну версию старше основных данных. Обычно важны основные. Если с ними что-то случилось, предыдущая копия может пригодиться.
> Расширение само не восстанавливает данные из копий. Это страховка: копии можно посмотреть в аккаунте Gists/WebDAV.

### Каталоги и имена файлов по умолчанию

**Основные данные Gists**
- Ключ описания: `__NiceTab_gist_key__`
- Файл списка: `__NiceTab_gist__.json`
- Файл настроек: `__NiceTab_settings_gist__.json`

**Резервные данные Gists**
- Ключ описания: `__NiceTab_gist_key_bak__`
- Файл списка: `__NiceTab_gist__.json`
- Файл настроек: `__NiceTab_settings_gist__.json`

**Основные данные WebDAV**
- Каталог: `__NiceTab_web_dav__`
- Файл списка: `__NiceTab_web_dav__.json`
- Файл настроек: `__NiceTab_settings_web_dav__.json`

**Резервные данные WebDAV**
- Каталог: `__NiceTab_web_dav_bak__`
- Файл списка: `__NiceTab_web_dav__.bak.json`
- Файл настроек: `__NiceTab_settings_web_dav__.bak.json`


## Панель управления - корзина

Удалённое из списка временно лежит в корзине. При ошибке данные можно восстановить.

Долго корзина ничего не хранит: она очищается каждый день. Восстанавливайте случайно удалённое в тот же день.

## Привязка сочетаний клавиш

Используется встроенная система команд браузера. Кнопка «Привязка сочетаний клавиш» открывает страницу настроек сочетаний браузера. Остальные сочетания настраиваются там же.

Кнопка есть и в popup, и на панели управления.

Сочетания по умолчанию:

| Действие | По умолчанию | Примечание |
| --- | --- | --- |
| Открыть панель NiceTab | macOS (⌥ + ⇧ + M) <br /> windows (Alt + Shift + M) | Буква `M` — от `manager` |
| Отправить все вкладки | macOS (⌥ + ⇧ + A) <br /> Windows (Alt + Shift + A) | Буква `A` — от `all` |
| Отправить текущую вкладку | macOS (⌥ + ⇧ + C) <br /> Windows (Alt + Shift + C) | Буква `C` — от `current` |

Остальные сочетания настраиваются на встроенной странице браузера.
