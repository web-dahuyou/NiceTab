## Обзор

**Примечание.** Расширение активно развивается. Скриншоты ниже могут относиться к предыдущим версиям. Рекомендуем устанавливать последний релиз.

- NiceTab — `открытое` расширение для быстрого и удобного управления вкладками браузера.
- Название `NiceTab` отражает цель — сделать «приятный» инструмент для вкладок.
- Аналог таких расширений, как `OneTab`, `Toby`, `SessionBuddy`, `N-Tab` и `KepTab`. Поддерживаются Chrome, Firefox, Microsoft Edge и другие браузеры на Chromium.
- Написано на `React` на базе [`WXT`](https://wxt.dev/) (есть шаблоны для `Vanilla`, `Vue`, `React`, `Svelte` и `Solid`).
- Интерфейс построен на [`Ant Design`](https://ant-design.antgroup.com/).


## Установка

- Интернет-магазин Chrome: [Chrome Web Store](https://chromewebstore.google.com/detail/fonflmjnjbkigocpoommgmhljdpljain)
- Надстройки Microsoft Edge: [Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/ompjiaelpibiggcnanhbdblkhfdmkgnl)
  (из-за более долгой модерации версия в магазине Edge может отставать от Chrome.)
- Дополнения Firefox: [Firefox Browser Addons](https://addons.mozilla.org/firefox/addon/nice-tab-manager)

### Примечания
Из соображений безопасности Firefox может блокировать привилегированные URL, например:
- chrome: URL
- javascript: URL
- data: URL
- file: URL
- привилегированные about: URL Firefox (например `about:config`, `about:addons`, `about:debugging`). Непривилегированные URL (например `about:blank`) разрешены.

Если адрес страницы подходит под один из этих случаев, вкладка может не открыться. Скопируйте URL и откройте его вручную.


## Возможности

Подробное руководство: <a href="./GUIDE-ru.md">руководство пользователя NiceTab</a>

### Общие возможности

- Отправка одним щелчком: все вкладки, все вкладки всех окон, текущая группа, текущая вкладка, остальные вкладки, вкладки слева и справа.
- Отправка нативных групп вкладок браузера в NiceTab и повторное открытие их как нативных групп.
- Сочетания клавиш браузера (открыть панель NiceTab, отправить все вкладки, отправить текущую вкладку и др.).
- Настройки предпочтений.
- **Импорт** в нескольких форматах и сохранение в локальный файл. Сейчас поддерживаются `NiceTab`, `OneTab`, `Toby`, `SessionBuddy` и `KepTab`. Другие форматы можно добавить позже.
- Настраиваемая **страница новой вкладки**.
- **Удалённая синхронизация**.
- Ручное переключение **светлой/тёмной** темы.
- **Смена цвета темы**, сейчас несколько готовых цветов (можно расширить позже).
- **Несколько языков**: китайский, английский и русский (правки формулировок и новые языки приветствуются).
- **Корзина**: удалённые вкладки, группы и категории можно восстановить или удалить навсегда.
- Ручная гибернация неактивных вкладок. Усыплённые вкладки остаются на панели и перезагружаются при активации.

### Управление списком

- Больше возможностей — в `руководстве пользователя`.
- Категории, группы вкладок и вкладки: сохранение, восстановление, избранное, блокировка, добавление, удаление, правка, поиск, перетаскивание и т.д.
- Глобальный поиск по вкладке и URL с переходом к результату.
- Блокировка категории от случайных действий.
- Сворачивание категорий, создание категорий и групп, перенос групп и вкладок в новые категории/группы.
- Сочетания клавиш для части операций, например сортировки категорий и групп.
- Сортировка групп по названию или времени создания.
- Копирование всех ссылок группы одним щелчком, с настраиваемым шаблоном.
- Ручное удаление дубликатов вкладок.
- Множественный выбор вкладок, перенос или копирование между группами.
- Свои заголовок и URL у вкладки.

### Настройки

- Подробности: `панель NiceTab > Настройки` или `руководство пользователя`.

### Удалённая синхронизация

- Синхронизация через `Gists` и `WebDAV`.
  - Gists: данные можно синхронизировать с GitHub или Gitee по личному access token (достаточно права `gists`). Другие платформы возможны позже.
  - WebDAV: URL, имя пользователя и пароль (можно несколько учёток WebDAV).
- Синхронизируются и список вкладок, и настройки.
- Автосинхронизация: включение/выключение, частота и способ.

**Примечание.** Объединяющая отправка не удаляет данные по diff: она объединяет удалённые и локальные данные и отправляет результат. Чтобы синхронизировать удаления, удалите элементы локально и вручную перезапишите удалённые данные.

## Скриншоты

### Значок расширения (Popup)

- По умолчанию щелчок по значку `NiceTab` открывает панель: список, настройки, импорт/экспорт, синхронизация и корзина.
- Можно быстро сменить цвет темы или посмотреть/закрыть открытую вкладку.
- Если в настройках не выбран ни один модуль popup, щелчок по значку отправляет все вкладки в NiceTab.

- Данные `OneTab`, `Toby`, `SessionBuddy` или `KepTab` можно импортировать и разобрать в формат `NiceTab`.

### Удалённая синхронизация

Поддерживаются Gitee Gists, GitHub Gists и WebDAV:
- Gists: синхронизация с аккаунтами GitHub и Gitee по access token.
- WebDAV: URL, имя пользователя и пароль (можно несколько учёток).

**Примечание:**
- Для gists достаточно права `gists`.
- Объединяющая отправка не удаляет по diff. Она объединяет удалённые и локальные данные и отправляет результат, поэтому вкладки только накапливаются. Чтобы синхронизировать удаления, удалите их локально и вручную перезапишите удалённые данные.

## Использование

- Щелчок по значку открывает popup с открытыми вкладками. Оттуда можно перейти в панель управления или сменить тему.
- Правый щелчок по значку показывает пункты отправки вкладок в NiceTab.
- В панели управления можно сменить язык, цвет темы и светлый/тёмный режим.
- `Панель > Список` — все отправленные вкладки по категориям и группам.
- `Панель > Настройки` — предпочтения расширения.
- `Панель > Импорт и экспорт` — импорт и экспорт в форматах NiceTab, OneTab, SessionBuddy, Toby или KepTab.
- `Панель > Синхронизация` — синхронизация с GitHub и Gitee по access token (достаточно права `gists`).
- `Панель > Корзина` — удалённые категории, группы и вкладки: восстановление или окончательное удаление.

### Примечания
Из соображений безопасности Firefox может блокировать привилегированные URL, например:

- javascript: URL
- data: URL
