## Архитектура

### Структура расширения

Расширение следует архитектуре WXT на основе entrypoints. Основные каталоги:

- **entrypoints/background/**: фоновый service worker — жизненный цикл расширения, события вкладок, бейдж и инициализация popup
- **entrypoints/popup/**: интерфейс popup (по щелчку на значке)
- **entrypoints/options/**: главная панель со страницами Список, Настройки, Импорт/экспорт, Синхронизация и Корзина
- **entrypoints/content/**: content scripts для контекстного меню на веб-страницах
- **entrypoints/common/**: общие утилиты, хранилище, хуки и константы
- **entrypoints/types/**: типы TypeScript всего расширения

### Управление данными

Используется Chrome Storage API и утилиты в `entrypoints/common/storage/`:

- **tabListUtils**: список вкладок (категории, группы, вкладки)
- **settingsUtils**: настройки пользователя
- **syncUtils**: синхронизация GitHub/Gitee Gists
- **syncWebDAVUtils**: синхронизация WebDAV
- **recycleBinUtils**: удалённые элементы для восстановления
- **themeUtils**: тема и цвета
- **stateUtils**: состояние приложения

Все утилиты хранилища — синглтоны через `instanceStore.ts` и дают реактивные слушатели хранилища.

### Основные модели данных

Типы заданы в `entrypoints/types/tabList.ts`:

- **TagItem**: категория с groupList
- **GroupItem**: группа вкладок с tabList
- **TabItem**: вкладка с URL, заголовком и favicon

Иерархия: TagItem (категория) → GroupItem (группа вкладок) → TabItem (вкладка)

### Интернационализация

Используется `react-intl`:
- Языки: упрощённый китайский (zh-CN), традиционный китайский (zh-TW), английский (en-US) и русский (ru-RU)
- Модули локалей в `entrypoints/common/locale/modules/`
- Локаль Ant Design через `antdMap`

### UI

- **React 18** и TypeScript
- **Ant Design 5.29.3** для компонентов
- **styled-components** для стилей
- **react-router-dom** для навигации страницы настроек
- **pragmatic-drag-and-drop** (Atlassian) для перетаскивания
- **react-virtuoso** для виртуальных списков (производительность)

### Разрешения расширения

Основные разрешения в `wxt.config.ts`:
- `storage`: сохранение данных
- `tabs`: управление вкладками
- `contextMenus`: контекстное меню
- `tabGroups`: нативные группы вкладок браузера
- `commands`: сочетания клавиш (только Chrome)
- `alarms`: расписание автосинхронизации
- `scripting`: внедрение content scripts

У Firefox часть разрешений условная из-за различий API.

## Ключевые файлы и паттерны

### Фоновый worker (`entrypoints/background/index.ts`)

- Инициализирует контекстные меню, команды клавиатуры и слушатели вкладок
- Ставит бейдж с числом открытых вкладок
- Настраивает заголовки страниц
- Инициализирует popup в зависимости от настроек

### Общие утилиты

- **contextMenus.ts**: регистрация и обработчики контекстного меню
- **commands.ts**: обработчики сочетаний клавиш
- **tabs.ts**: операции с вкладками (создание, закрытие, гибернация и т.д.)
- **keyMap.ts**: карта сочетаний клавиш
- **constants.ts**: константы и перечисления свойств настроек

### Структура страницы настроек

Каталог `entrypoints/options/`:
- **home/**: список вкладок с деревом навигации
- **settings/**: формы предпочтений
- **importExport/**: импорт и экспорт
- **sync/**: удалённая синхронизация (Gists/WebDAV)
- **recycleBin/**: восстановление удалённых элементов

### Важные хуки

- **global.ts**: глобальная шина событий и сообщения
- **selectionBox.ts**: рамка множественного выбора
- **themeColors.ts**: цвета темы
- **treeData.ts**: операции дерева категорий и групп

## Правила разработки

### Обязательный export

**Важно:** в каждом файле `.js`, `.ts`, `.tsx` должен быть `export default`. Без него локальный сервер выдаст ошибку.

### Алиас путей импорта

Для импортов из `entrypoints` используется алиас `~`:
```ts
import { something } from '~/entrypoints/common/utils';
```

### Стили

- styled-components для стилей компонентов
- тема Ant Design для единообразия UI
- цвета темы через themeUtils
- поддерживаются светлый и тёмный режимы

### API браузера

Используйте `browser.*` (кроссбраузерная обёртка WXT), а не `chrome.*`:
```ts
browser.tabs.query({}) // вместо chrome.tabs.query({})
```

### Хранилище

Вызывайте готовые утилиты, а не Storage API напрямую:
```ts
// Правильно
const settings = await settingsUtils.getSettings();

// Избегать
const settings = await storage.getItem('settings');
```

### Типы

Перед коммитом запускайте `pnpm run compile`.

### Сообщения коммитов

Соглашения Angular:
- `feat:` новая возможность
- `fix:` исправление ошибки
- `docs:` документация
- `refactor:` рефакторинг
- `style:` форматирование
- `test:` тесты
- `chore:` обслуживание

## Особенности браузеров

### Отличия Firefox

Во Firefox ограничены привилегированные URL:
- нельзя открыть URL `chrome:`, `javascript:`, `data:`, `file:`
- нельзя открыть привилегированные `about:` (например `about:config`)
- разрешение `tabGroups` необязательное (нужно согласие пользователя)
- разрешений `commands` и `favicon` нет

Для условной логики используется флаг `isFirefox` из `wxt.config.ts`.

### Политика безопасности контента

В `wxt.config.ts` разные CSP для Firefox и Chrome из-за более строгих требований Firefox.

## Тесты и качество

Автотестов пока нет. Качество обеспечивается так:
- проверка типов TypeScript (`pnpm run compile`)
- линтинг ESLint (`pnpm run lint`)
- ручное тестирование в браузерах

## Удалённая синхронизация

Поддерживаются несколько бэкендов:
- **GitHub Gists**: личный access token с правом `gists`
- **Gitee Gists**: альтернатива, если GitHub недоступен
- **WebDAV**: несколько учёток WebDAV

Стратегия: объединение (удаления по умолчанию не синхронизируются). Чтобы синхронизировать удаления, нужно вручную перезаписать удалённые данные.

## Производительность

- **react-virtuoso** для виртуальной прокрутки больших списков
- **lodash-es** (ES-модули для лучшей сборки)
- debounce обработчиков, чтобы не вызывать API слишком часто
- слушатели хранилища с эффективным diff

## Манифест расширения

WXT генерирует manifest.json из `wxt.config.ts`. Важное:
- локаль по умолчанию: `zh_CN`
- сочетания клавиш в секции `commands`
- homepage URL ведёт на GitHub
- отдельные настройки для Firefox gecko
